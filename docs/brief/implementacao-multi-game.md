## 📝 COPY STYLE GUIDE

### Tom Geral
- Casual mas profissional
- Game references naturalemente integradas
- Sem favoritism a um game específico
- Divertido + Confiável

### Exemplos (Português)

**Genérico (Pode usar qualquer game):**
- "Pressione START pra continuar"
- "Level Up! 🚀"
- "Desafio aceito?"
- "Sua aventura começa agora"

**Alternância (Cada seção pode escolher):**
- Sobre: "Boss Introduction" (Mega Man)
- Projetos: "Pokédex Entry" ou "Treasure Chest"
- Skills: "Type Matchup" (Pokémon) ou "Robot Master" (Mega Man)
- Contato: "Boss Fight" (Mega Man)

**Achievements:**
- "Code Master!" (todos)
- "100% Completion!" (Pokémon vibe)
- "All Bosses Defeated!" (Mega Man vibe)
- "Treasure Hunter!" (Zelda vibe)

## ✅ QUALITY CHECKLIST

- [ ] Nenhum game aparece mais de 16% (max)
- [ ] Todos os 7 games têm 5+ easter eggs mínimo
- [ ] Sound effects não overlap (cada ação tem 1 som claro)
- [ ] Paleta de cores balanceada (não só vermelho ou azul)
- [ ] Copy neutro (lê-se bem sem forçar game references)
- [ ] Mobile responsive (teste em 375px - 1440px)
- [ ] Accessibility A11y completo (contraste, alt text, etc)
- [ ] Performance: Lighthouse 90+
- [ ] Sprites carregam rápido (otimized PNG/WebP)
- [ ] Animações não lagam (60fps target)
- [ ] Easter eggs não são óbvios (desafio discovery)
- [ ] Leaderboard funciona (mesmo sem backend)
