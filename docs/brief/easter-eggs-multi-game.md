## 🎮 EASTER EGGS EQUILIBRADOS POR GAME

### 1️⃣ SUPER MARIO EASTER EGGS

```
🎯 SUPER MARIO JUMP
   Digitar: "MARIO" + JUMP
   → Personagem sprite executa pulo (M-key sound efeito)
   → Screen tremendo tipo "hit" (11 pixels up/down)
   → Som: Power-up jingle (5 segundos de duração)
   → Reward: +100 XP, badge "Mario Fan"

🎯 COIN COLLECTION
   Clicar 8x no logo
   → Animação de moedas aparecendo (spinning coins)
   → Som: "Ding!" tipo recolher moeda Mario
   → Contador apareça: "COINS: 8/80"
   → Milestone 80 coins = "1-UP!" extra life / secret content

🎯 POWER-UP MUSHROOM
   Scroll até Skills + hover 10 segundos na mesma skill
   → Personagem come cogumelo
   → Tamanho aumenta 1.5x (Big Mario mode)
   → Barra de HP fica cheia
   → Duração: 10 segundos
   → Depois volta ao normal (shrinking animation)

🎯 FLAG POLE ENDING
   Completar 100% dos projetos
   → Personagem corre pra flag pole
   → Pula e toca no topo
   → Transição pra tela de congratulações tipo "World 1-1 Complete"
   → Som: "Level complete" fanfare

🎯 BOWSER'S CASTLE
   Botão escondido no footer (muito pequenininho)
   → Abre "Dark Mode Ultra" com tema preto/vermelho Bowser
   → Fundo muda para "Bowser's Castle"
   → Sprite personagem vira King Koopa estilo
   → Efeito: Tudo fica invertido/darker
```

### 2️⃣ POKÉMON EASTER EGGS

```

   → Select "Capture" → Pokéball throw animação

   → Efeito de brilho/sparks

🎯 POKÉMON EVOLUTION
   Quando completar projeto skill (80%+)
   → Pop-up: "[Skill Name] is evolving!"

   → Skill "evolui" pra forma melhorada (ícone muda, cor mais brilhante)
   → Som: "Evolução" jingle Pokémon

🎯 PROFESSOR OAK APPEARS
   Scroll até o footer + clique footer 10x
   → ASCII art de Professor Oak aparece
   → Mensagem: "Parabéns! Você é um Pokémon Master Developer!"
   → Link secreto revela "Master Developer Bonus Content"

🎯 SHINY POKÉMON MODE
   Hover na skill bar enquanto toca a música de fundo
   → 1 em 4096 visitas: "SHINY!" animação brilho dourado
   → Skill fica com aura especial
   → Efeito: "Found a Shiny Skill! Very Rare!" + XP bônus

### 3️⃣ THE LEGEND OF ZELDA EASTER EGGS

```
🎯 OPEN TREASURE CHEST
   Cada projeto card é uma "Treasure Chest"
   → Hover: Chest brilha
   → Click: Chest abre com animação (tipo Zelda chest open)
   → Som: Zelda "treasure open" jingle
   → Mostra conteúdo dentro (projeto details)

🎯 SECRET PASSAGE
   Digitar "SECRET" enquanto está em qualquer seção
   → Mapa escondido aparece no canto (mini-map)
   → Revela "secret passages" em diferentes seções

   Completar ações no site (visit sections, contact form)
   → Pequenas moedas vermelhas/azuis/verdes aparecem
   → "Rupees Collected: [número]"
   → Milestone: 100 rupees = "Unlock Secret Area!"

🎯 MASTER SWORD UNLOCK
   Completar 5+ projetos
   → Badge "Master Sword" desbloqueado
   → Personagem sprite pode usar "Master Sword stance"
   → Efeito visual: Brilho azul especial

🎯 HEART CONTAINER
   Hover em "Contact" section por 5+ segundos
   → Animação de coração pulsante
   → Som tipo Zelda "get item" jingle
   → +1 Heart (max HP aumenta)
   → Mostra counter visual de hearts

🎯 LOST WOODS
   Usar setas do teclado (↑ ↓ ← →) pra navegar ao invés de click
   → Efeito "Lost Woods" plays (Zelda theme music snippet)
   → Navegação "aleatória" se errar a sequência
   → Encontrar caminho correto = "Found the exit!" XP bonus

### 4️⃣ PAC-MAN EASTER EGGS

```
🎯 GHOST FOLLOWERS
   Deixar mouse parado por 5 segundos
   → 4 "fantasmas" aparecem (estilo Pac-Man: Blinky, Pinky, Inky, Clyde)
   → Seguem o personagem sprite
   → Click para "comê-los" → Power-up mode (10 segundos)
   → Som: "Powerpellet" and "Ghost eaten" plinky sounds

🎯 MAZE NAVIGATION
   Mini-game ativado por easter egg
   → Pequeno Pac-Man maze aparece em overlay
   → User controla com setas
   → Coletar "pellets" ganha XP
   → Evitar "fantasmas"
   → Completar maze = "Maze Master!" badge

🎯 PELLET TRAIL
   Enquanto personagem sprite se move
   → Deixa "pellet trail" atrás dele (pequenos círculos)
   → Usuário pode recolher pellets que deixa
   → +10 XP por pellet
   → Visual: Trail desaparece após 5 segundos

🎯 SIREN SOUND
   Quando user está "hunted" por ghost (Easter egg ativo)
   → Siren sound tipo Pac-Man aumenta volume conforme proximidade
   → Velocidade aumenta (tension building)
   → Efeito: Screen tem subtle red tint

🎯 TUNNEL WARP
   Encontrar "tunnel" escondido (ex: scroll muito rápido)
   → Personagem warpa pro outro lado (Pac-Man style)
   → Efeito: Brief screen flash e whoosh sound
   → Transição suave entre seções
```

## 🎯 DISTRIBUTION STRATEGY

### Por Seção do Site

#### Hero / Header
- **Mario**: Coin counter, jump animation
- **Sonic**: Speed boost intro, zone music
- **Mega Man**: Stage select tease
- **Zelda**: Open chest teaser

#### Sobre
- **Castlevania**: Stairs climb effect
- **Mega Man**: Boss introduction (personagem description as boss)
- **Mario**: Power-up progression (levels shown as mushrooms)
- **Pokémon**: Professor Oak cameo option

#### Projetos
- **Zelda**: Treasure chest cards (primary)
- **Pokémon**: Pokédex entries (secondary)
- **Mega Man**: Robot Masters labeling
- **Pac-Man**: Maze navigation mini-game (rare unlock)

#### Skills
- **Pokémon**: Type system + Evolution mechanics
- **Mega Man**: Weapon upgrades + Robot Master skills
- **Mario**: Power-ups system (temporary boosts)
- **Sonic**: Rings/Protection system

#### Experiência
- **Sonic**: Zone progression (cada período é uma zone)
- **Castlevania**: Staircase climbing aesthetic
- **Mega Man**: Stage progression + boss battles
- **Zelda**: Dungeon progression feeling

#### Contato
- **Mega Man**: Boss fight animation
- **Pokémon**: Pokéball throw capture
- **Mario**: "Send to Bowser's Castle" theme option
- **Castlevania**: Holy location (safe space to contact)

#### Footer
- **Pac-Man**: Ghost credits, maze pat patterns
- **Sonic**: Credits roll with zone themes
- **All Games**: Credits Easter egg (secret developer names as characters)
